# LearnWorlds Automation

This repository contains a small automation flow for updating session dates in LearnWorlds pages from CSV files.

## Workflow

The expected execution order is:

1. `calcular_datas.py`
2. `gerar_dados.py`
3. `atualizar_links.py`

### Step 1: Calculate the next session dates

Script: `calcular_datas.py`

- Reads `orig.csv`
- Uses the last filled session date in each trainer row as the reference
- Builds the next 4-session sequence
- Preserves the original time and timezone text
- Writes the result to `orig_teste.csv`

### Step 2: Convert the calculated data

Script: `gerar_dados.py`

- Reads `orig_teste.csv`
- Converts the wide trainer/session format into one row per session
- Writes the result to `dados.csv`

### Step 3: Update LearnWorlds

Script: `atualizar_links.py`

- Reads `dados.csv`
- Logs into LearnWorlds with credentials from `.env`
- Opens each session page in Playwright
- Finds the matching trainer card
- Replaces the `Date and time` text
- Saves the page

## Files

- `orig.csv`: source data used as the input base
- `orig_teste.csv`: calculated output generated by `calcular_datas.py`
- `dados.csv`: linear automation input generated by `gerar_dados.py`
- `calcular_datas.py`: date calculation step
- `gerar_dados.py`: CSV transformation step
- `atualizar_links.py`: LearnWorlds browser automation step
- `.env`: local credentials and login configuration for LearnWorlds

## Requirements

- Python 3
- `pandas`
- `python-dotenv`
- `playwright`
- Chromium installed for Playwright

## Environment

Create a local `.env` file with:

```env
LW_EMAIL=your-email
LW_PASSWORD=your-password
LW_LOGIN_URL=https://training.tergar.org/author/dashboard
```

Do not commit `.env`.

## Run

If you use the local virtual environment:

```bash
./venv/bin/python calcular_datas.py
./venv/bin/python gerar_dados.py
./venv/bin/python atualizar_links.py
```

## Repository Notes

- This repository is intended for private use.
- URLs and trainer operational data may be stored here if that is acceptable for your internal workflow.
- Credentials must stay out of version control.
- If the repository is ever shared outside the trusted team, review the CSV files before publishing.
